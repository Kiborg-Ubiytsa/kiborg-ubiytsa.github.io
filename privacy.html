Политика конфиденциальности

Действует с 13 октября 2026 года.

Приложение Liga Banki Publisher использует YouTube API Services и получает доступ только к YouTube-каналу «Лига Банки», принадлежащему владельцу приложения, после его явного согласия.

  • Какие данные: публичные и аналитические показатели роликов канала (просмотры, лайки, досмотр, прирост подписчиков) и тексты комментариев под роликами канала.
  • Зачем: чтобы подсчитать голоса зрителей за персонажей и выбрать подачу следующих роликов. Данные не продаются и не передаются третьим лицам для рекламы.
  • Где хранятся: сводные показатели и короткие выборки комментариев хранятся в закрытом репозитории владельца канала. Личные данные авторов комментариев не собираются отдельно.
  • Обработка: тексты комментариев могут обрабатываться сервисом ИИ для подсчёта голосов.
  • Удаление: доступ можно отозвать в любой момент на странице настроек безопасности Google; по запросу данные удаляются.

Приложение соблюдает Условия YouTube API Services и Политику конфиденциальности Google. Связь: youtube.com/@ligabanki.

Privacy Policy. Liga Banki Publisher uses YouTube API Services and accesses only the owner's own channel “Лига Банки”, with the owner's consent. It reads video statistics and comment texts of that channel to count viewer votes and plan future videos; comment texts may be processed by an AI service for vote counting. Data is not sold or shared for advertising. Access can be revoked at any time via Google security settings. See the Google Privacy Policy.
